# doc-consistency-auditor · 教学说明

> 挑战：C4 技能分享与传播
> 目标：让一个**陌生人**照着这份说明，5 分钟内跑起来并看懂报告。

---

## 一、如何上手（给从没碰过的人）

### 第 1 步：确认环境

只要电脑上有 **Python 3.8 或更高版本**即可，不需要装任何第三方库。

```bash
python3 --version   # 看到 3.8+ 就行
```

### 第 2 步：拿到文件

把 `doc-consistency-auditor/` 这个文件夹整个拷走。里面就三样东西：

```
doc-consistency-auditor/
├── SKILL.md                       # 主指令（说明它是干什么的）
├── scripts/audit.py               # 真正干活的脚本
└── references/
    ├── glossary.example.yaml      # 术语表样例（可照抄改）
    └── manifest.example.yaml      # 交付物清单样例（可照抄改）
```

### 第 3 步：跑第一次（最简单）

进入文件夹，指向你要检查的 Markdown 文件或目录：

```bash
cd doc-consistency-auditor
python3 scripts/audit.py --path /你要检查的文档路径
```

没有报错、最后是「✅ 审计通过」= 干净；出现「⚠️ 审计发现 N 个问题」= 逐条看报告改。

### 第 4 步：读懂报告

每条问题都是这个格式：

```
[01] [错误] R1 @ sample_bad.md:11 出现禁用写法「github」
     → 建议：统一为「GitHub」
```

- `[01]` 序号；`[错误]/[警告]` 严重度；`R1` 规则号；`sample_bad.md:11` 文件+行号。
- **错误（error）** 通常是断链、术语漂移，建议改。
- **警告（warning）** 通常是标题层级跳跃、重复标题、交付物缺失，按需处理。

### 第 5 步：复跑确认

改完再跑一遍，直到退出码为 `0`。

## 二、常见坑（我踩过的，提前告诉你）

1. **术语表大小写敏感**：`forbidden: ["github"]` 只匹配小写 `github`，不会匹配 `Github`。要把所有变体都写进去：`["github", "Github", "GH"]`。
2. **代码块里的词会自动跳过**：脚本不检查 ` ``` ` 代码围栏内部的文字，所以代码里的 `github` 不会被误报——这是特性，不是 bug。
3. **外部链接不做网络请求**：`https://...`、`mailto:`、`tel:` 直接跳过不校验（保持离线、确定性）。所以它只查**内部相对链接**和**锚点**，不查外链死没死。
4. **锚点要跟标题 slug 一致**：`[说明](#config)` 要求文件里真有标题「config」或「Config」。中文标题的锚点 slug 规则在 GitHub 里是"去标点、空格换连字符"，若你的链接对不上，先检查标题原文。
5. **超大文件默认跳过**：超过 5MB 的 .md 会被跳过并报 R0 警告，用 `--max-bytes` 调高上限。这是为了防止把整个仓库拖进内存。
6. **路径别用变量/通配符**（在受控脚本环境里）：直接写死显式相对路径最稳。
7. **没传 `--glossary` 时 R1 自动跳过**：不是漏报，是"没给术语表就不知道什么叫漂移"。

## 三、优化技巧（进阶）

1. **挂进 CI**：在 GitHub Actions 里加一步 `python3 scripts/audit.py --path . --manifest ...`，提交不过审就别想合并。
2. **自定义术语表**：把你们项目的专有名词、缩写、大小写规范写进 `glossary.yaml`，团队口径一次锁定。
3. **自定义交付物清单**：改 `manifest.yaml` 的 glob，让它在你们提交前自动喊"缺了 X"。
4. **`--json` 给脚本消费**：想在自己的 pipeline 里拿结果，用 `--json` 解析，别去截终端文本。

## 四、教别人用（一句话话术）

> 这是我的 C4 技能 —— **doc-consistency-auditor（Markdown 文档一致性审计器）**，输入一个 Markdown 文件或目录，就能得到一份带「文件:行号」的问题清单（术语漂移/断链/标题层级/重复标题/交付物缺失）。`python3 scripts/audit.py --path 你的文档` 一条命令，欢迎大家试用和反馈！
