# doc-consistency-auditor · Skill 说明

> 挑战：C4 技能分享与传播
> 技能名：doc-consistency-auditor（Markdown 文档一致性审计器）
> 提交人：2025105400130

---

## 一句话说明

**输入**一个 Markdown 文件或目录（可附术语表 YAML + 交付物清单 YAML），**输出**一份结构化审计报告（终端 + Markdown + JSON）+ 退出码，精确定位五类"看不见的坑"。

## 解决什么问题

多人协作、AI 批量产出、或长时间维护的 Markdown 文档，最常见五类一致性问题：

| 规则 | 问题 | 后果 |
|------|------|------|
| R1 术语漂移 | 同一概念一会儿「术语表」一会儿「词汇表」、`github`/`Github`/`GitHub` 混用 | 读者困惑、检索失配 |
| R2 失效链接/锚点 | 改了标题后 `#锚点` 失效、图片/相对路径指向不存在的文件 | 点击 404、内容断裂 |
| R3 标题层级跳跃 | `##` 直接跳到 `####` | 目录树断裂、可读性差 |
| R4 重复标题 | 同一文件两个「## 概述」 | 锚点歧义、引用错乱 |
| R5 交付物缺失 | 该交的文件（README / .skill / AI日志 / AAR / skill说明）没交 | 提交不完整被拒 |

人工逐篇检查费时且极易漏。本技能用一个**确定性脚本**一次性扫出问题，并给出精确到 `文件:行号` 的位置和修复建议。

## 使用场景

- **交作业/交付前自检**：对照交付物清单，确保该交的文件一个不少、命名规范。
- **多人协作文档统一**：用术语表约束团队写法，避免"你说的 A 和我说的 A 不是一个 A"。
- **CI / 提交前把关**：把 `audit.py` 挂进 GitHub Actions 或 git pre-commit hook，实现"提交前必过一致性检查"。

## 输入输出

| 项 | 说明 |
|----|------|
| 输入 | `.md` / `.markdown` 文件，或目录（递归扫描，自动跳过隐藏目录） |
| 可选输入 | `--glossary 术语表.yaml`（启用 R1）；`--manifest 交付物清单.yaml`（启用 R5） |
| 输出 | 审计报告：终端（默认）/ `--out 报告.md`（Markdown）/ `--json`（机器可读） |
| 退出码 | `0`=无问题；`1`=发现问题；`2`=参数/路径错误 |

## 使用步骤

```bash
# 1) 最简：只查链接/标题/术语漂移之外的检查（不传术语表则跳过 R1）
python3 scripts/audit.py --path ./docs

# 2) 完整：术语 + 链接 + 标题 + 交付物清单
python3 scripts/audit.py --path ./docs \
  --glossary references/glossary.example.yaml \
  --manifest references/manifest.example.yaml \
  --out audit_report.md

# 3) 机器可读
python3 scripts/audit.py --path ./docs --json
```

## 真实案例（本次自测）

- **干净样例** `demo/sample_clean.md` → 退出码 `0`，报告「未发现一致性问题」✅
- **坏样例** `demo/sample_bad.md` → 退出码 `1`，精确报出 7 个问题（错误 6 / 警告 1）：
  - R1：`sample_bad.md:11` 出现禁用写法 `github`
  - R2：断链 `./install.md`、`./deploy.md`、锚点 `#config` 均不存在
  - R4：重复标题「配置环境变量」
- **目录 + 交付物清单** → 正确报告 R5 缺失：`README.md`、`*.skill`、`AI日志*.md`、`AAR*.md`、`skill说明*.md`

## 四条件自检

| 条件 | 如何满足 |
|------|----------|
| 可复用 | Python 3.8+ 仅标准库（argparse/os/re/json/fnmatch/sys），零第三方依赖，`python3 audit.py` 直接跑 |
| 可执行 | 真实可运行脚本 `scripts/audit.py`，非纯理论 |
| 可验证 | 给定含已知错误的样例，精确报出 `文件:行号:问题`；干净样例返回退出码 0 |
| IO 明确 | 输入路径 → 输出报告 + 退出码，一句话说清 |
