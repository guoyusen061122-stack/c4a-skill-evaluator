# deliverable-checker 教学说明 — 从零教会你用

> 目标读者：完全没接触过命令行的同学。跟着做，5 分钟内跑出你的第一份自查报告。

## 这个技能是干嘛的（30 秒版）

交作业前，它替你检查三件事：**交齐没有、命名对不对、会不会踩红旗**。
你给它两个文件夹路径，它还你一份报告 + 一张待办清单。

## 第一步：准备环境

唯一要求：电脑上有 **Python 3.8 或更高版本**（只用到标准库，什么都不用装）。

检查方法：打开终端（Windows 按 `Win+R` 输入 `cmd`），输入：

```
python --version
```

显示 `Python 3.x.x` 就行。显示"不是内部或外部命令"→ 去 python.org 下载安装，
安装时**勾选 "Add Python to PATH"**。

## 第二步：拿到技能包

从群里下载 `苗文馨_C4_deliverable-checker.skill`，它本质是一个 ZIP 压缩包：

- 手动解压：右键 → 重命名为 `.zip` → 解压（Windows），或 `tar -xzf` / 解压软件（macOS/Linux）
- 解压后得到 `deliverable-checker/` 文件夹，里面的 `scripts/deliverable_checker.py` 就是主程序

## 第三步：跑起来

在终端里（把路径换成你自己的）：

```bash
python 路径/deliverable-checker/scripts/deliverable_checker.py --challenge "挑战资料包目录" --submission "你的提交文件夹" --name "你的名字"
```

**两个路径怎么填：**
- `--challenge`：挑战官方资料包的文件夹（里面有 `challenge.json` 的那个目录）
- `--submission`：你自己放的交付物文件夹（子文件夹也会被扫描到）

跑完终端直接打印报告。加 `--output "报告.md"` 可以存成文件。

## 第四步：看懂报告（只看两处就够）

1. **第 1 节的 ❌**：缺的交付物，照着补
2. **第 5 节「行动清单」**：按顺序做完，再跑一遍，直到看到 ✅ 全绿

## 装进 AI 助手（推荐，免敲命令）

如果你用 WorkBuddy / Claude 这类支持 skill 的 AI：

1. 把 `.skill` 文件（ZIP 格式）导入技能目录
2. 对 AI 说：**"帮我自查 C4 的提交，资料包在 xxx，提交夹在 xxx"**
3. AI 会读 SKILL.md 自动调用脚本并帮你解读报告

## 常见坑（都是真实踩过的）

| 坑 | 现象 | 解法 |
|----|------|------|
| PATH 没配 | `python` 命令找不到 | 重装 Python 并勾选 Add to PATH，或用 `py` 代替 |
| 中文路径乱码 | 报告里文件名变 `???` | 用 Python 3.8+（默认 UTF-8）；终端执行 `chcp 65001` |
| 路径带空格报错 | 参数被拆开 | 整个路径用英文双引号包起来 |
| 没有 challenge.json | 报错"找不到 challenge.json" | 用 `--pattern "*skill说明*,*.skill,..."` 手动给清单 |
| 报告被自己扫进去 | 报告里出现上一份报告 | 不会——脚本自动跳过 `自查报告*` / `*_check_report*` |

## 优化技巧

- **存 JSON 接自动化**：`--json result.json` 输出机器可读结果，可以写进你的提交流水线或 CI
- **退出码用法**：`0`=全通过，`1`=有问题，`2`=输入错误。写批处理时用 `if errorlevel 1` 拦截
- **换挑战零成本**：C1–C7 通用，只要那个挑战有 challenge.json；没有就 --pattern
- **给助教用**：写个循环遍历每个人的文件夹，一口气输出全班的缺口总表

## 学完后你能举一反三的三件事

1. **通配符核对的通用套路**：任何"清单 vs 实物"的核对（面试材料、报销单据、参赛作品）都能套这个模式
2. **脚本驱动 vs 指令驱动技能的选型**：要确定性 → 脚本；要判断力 → 指令
3. **"诚实边界"设计**：让工具只做自己确定性能做的部分，其余明确标注交给 AI/人——这是人机协作工作流的核心设计模式
