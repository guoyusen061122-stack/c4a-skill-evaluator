## 0. 学完你能做到什么

- 30 秒内查出：这次挑战你**还缺哪些交付物**；
- 一眼看出：某个文件是"你以为交了、平台认为没交"的危险情况；
- 提交前避开**会让整单被拒**的标题写法。

## 1. 先讲一个真实的故事（5 分钟，不要跳过）

C3 我交了 3 个文件，其中一个叫 `AI_工作日志与AAR.md`。
我以为它同时满足了 `*AI日志*` 和 `*AAR*` 两个要求。

平台返回：`*AI日志*` → **缺失**。

为什么？因为平台的通配符**不是模糊匹配，而是文件名的字面子串匹配**。
`AI_工作日志与AAR.md` 里，`AI` 和 `日志` 中间隔着一个下划线，
并不存在 `AI日志` 这个**连续**的字符串。

> 一句话记住：**平台只认"一字不差连着写"的关键词。**
> 能匹配 `*AAR*`，但匹配不了 `*AI日志*`。

正确做法：把文件名改成 `AI日志与AAR.md`（去掉下划线），
**一个文件同时命中两个要求**。

第二个坑更隐蔽：标题写成 `C4 技能分享: xxx` 会因为**英文冒号 + 空格**
被敏感信息过滤判成"疑似密钥形态"，整单拒绝。换成 `-` 或全角 `：` 即可。

## 2. 工具怎么用（10 分钟，跟着做）

### 第 1 步：准备

需要 Python 3（本机已有）。**不需要装任何第三方包**——只用标准库。

解包技能：

```bash
# .skill 就是 tar.gz，直接解
tar -xzf ZhouYan05_C4_deliverable-selfcheck.skill
cd deliverable-selfcheck
```

### 第 2 步：把挑战要求抄下来

打开挑战页，找到"交付物"一栏，**原样复制**，用逗号连接，整体加引号：

```
"*skill说明*,*.skill,*教学说明*,*demo*,*AI日志*"
```

> 引号一定要加，否则 `*` 会被 shell 当成通配符展开。
> Windows PowerShell 里用单引号也可。

### 第 3 步：跑自检

```bash
python scripts/selfcheck.py \
  --workdir ./my_challenge \
  --required "*skill说明*,*.skill,*教学说明*,*demo*,*AI日志*" \
  --prefix ZhouYan05 \
  --title "你准备提交的标题" \
  --summary "你准备提交的摘要"
```

### 第 4 步：看结论

- 输出末尾的 `结论: **READY**` → 可以提交；
- `结论: **BLOCKED**` → 看下面的 `## 风险与待办`，**每条都写了"下一步"**，
  照着做就行。

想接进脚本/CI：加 `--json`；退出码 `0`=READY，`1`=BLOCKED。

## 3. 怎么读报告（关键技能）

报告里的每条代码含义：

| 代码 | 人话 |
| --- | --- |
| `LITERAL_MISMATCH` | 你有个文件"看起来能命中"，但平台不认。**改文件名，别改平台** |
| `EMPTY_FILE` | 0 字节占位文件，会被当成无效交付 |
| `MISSING_PREFIX` | 文件名没带你自己的前缀（如 `ZhouYan05_`） |
| `SENSITIVE_SHAPE` | 标题/摘要里有"英文冒号+空格"，会把整单拖下水 |
| `SENSITIVE_KEY` | 疑似真密钥。**不要提交**，先去吊销 |

## 4. 三个常见误解（课堂讨论用）

1. **"我文件名里有 AI 也有日志，凭什么不算？"**
   —— 平台判的是**连续子串**，不是"关键词都出现过"。这是本课最重要的认知纠正。

2. **"缺一个，我建个空文件占位不就行了？"**
   —— 不行。平台会标 `missing_artifacts` 红标，完成度上限被压到 ≤5/15。
   工具也会把它标成 `EMPTY_FILE` 风险。**宁可少而实。**

3. **"自检过了是不是就一定能提交成功？"**
   —— 不一定。工具是平台的**近似实现**，用来提前发现问题。
   最终以平台 `prepare-submission` / `submit` 的返回为准。
