# 阮如意_C4_教学说明：怎么用 challenge-preflight

本文件教你**把技能跑起来**、**读懂报告**、**避开踩过的坑**。

---

## 0. 30 秒上手

```bash
python scripts/preflight.py --dir "<你的交付目录>" --challenge C4 --name 你的姓名
```

看到第一行出现 `结论：PASS`，就可以去提交了。

---

## 1. 环境要求

- **Python 3.9 或更高**（命令行敲 `python --version` 能出版本号即可）
- **不需要联网、不需要 pip install**：只用标准库
- 想在本机看到报告里的彩色/排版效果，用任意能显示 Markdown 的编辑器打开即可（报告本身就是 Markdown）

---

## 2. 第一次运行（分步）

1. **找对目录**：打开你准备上传文件夹的**上一层**，确认你要指的就是那个「要交出去的文件夹」本身。
2. **运行命令**（把 `<...>` 换掉）：
   ```bash
   python scripts/preflight.py --dir "C:\...\我的挑战有哪些\C4" --challenge C4 --name 阮如意
   ```
3. **看第一行结论**：`结论：PASS` 或 `结论：FAIL`。
4. **FAIL 时只做一件事**：翻到报告末尾的「行动项」，从上往下逐条改。
5. **改完再跑**：同一目录、同一命令，结果稳定可复现。

> 想给机器读：加 `--json`，输出结构化报告，可以直接接进你的脚本 / CI。

---

## 3. 读懂报告

报告分七类检查，每类都有明确结论：

| 检查 | 说明 | 判定 |
| --- | --- | --- |
| 必交项齐全性 | 用该挑战的规则逐条匹配文件名 | 缺件 = FAIL |
| 姓名前缀 | 文件名是否带姓名（如 `阮如意_C4_…`） | 不带 = FAIL |
| 空文件 | 扫 0 字节文件 | 有 = FAIL |
| 残留标记扫描 | 正文里未清理的标记词 | WARN |
| 杂物清单 | `.git`、临时目录、缓存 | WARN |
| 体量统计 | 文件数、总体积、Top 20 大文件 | 提示 |
| 内容与文件类型一致性 | 图标/占位式文件、可执行性 | 提示 |

**哪些会让你失败**：缺件、无姓名前缀、空文件 —— 这三个直接 `FAIL`。
**哪些只是提醒**：残留标记、杂物、体量 —— 是 `WARN`，需要你人眼确认，不阻断。

---

## 4. 常见坑（都是我实测踩过的）

| 坑 | 现象 | 怎么办 |
| --- | --- | --- |
| 目录指错一层（多指或少指一层） | 报告说缺件，但文件其实在 | 目录必须是「要上传的那一层」本身 |
| 把 `ignorePaths` 里的通配当成正则写 | 脚本报 `re.error: multiple repeat` | v1.0 已改成按通配（glob）匹配，照 `skill_src/**` 这种写法即可 |
| 残留标记**误报** | 正文里正当地讨论「以后再补」这类措辞也被标出 | 这是 WARN，人眼确认；确实没问题就用 `--ignore <通配>` 排除 |
| 技能扫到自己 | 把技能源码目录一起扫，必然命中技能里的说明文字 | C4 规则已内置 `ignorePaths:["skill_src/**"]`，默认跳过 |
| 空文件 | 建了文件没写内容，等于没交 | 补内容，或删掉它 |
| `PASS` 了却被平台退回 | 规则快照过期 | 看 `references/rules.json` 里每条规则的 `source`，同步新规范 |

---

## 5. 优化技巧

- **串进流程**：`python scripts/preflight.py … && python <提交脚本>` —— 预检不过就不提交，省一次被打回。
- **接 CI / 自动脚本**：加 `--json` 拿结构化结果。
- **收新挑战**：在 `references/rules.json` 的 `challenges` 下加一项 —— `include`（正则数组）、`min`（最少命中数）、`namePrefixed`（是否要求姓名前缀）。
- **临时排除**：`--ignore "draft/**"` 可重复多次，只影响当次运行。
- **换人用**：`--name` 控制姓名前缀推断；不传也能自动猜。

---

## 6. 一页速查

```
# 基本用法
python scripts/preflight.py --dir <目录> --challenge C4

# 指定姓名前缀
python scripts/preflight.py --dir <目录> --challenge C4 --name 阮如意

# 机器可读
python scripts/preflight.py --dir <目录> --challenge C4 --json

# 临时排除某些路径（可重复）
python scripts/preflight.py --dir <目录> --challenge C4 --ignore "draft/**"

# 退出码：0 = PASS，1 = FAIL，2 = 参数 / 环境错误
```

**只记一件事**：跑 → 看行动项 → 补 → 再跑，直到 `PASS`。
