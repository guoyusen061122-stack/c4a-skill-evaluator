## 第一条 · 发布

> 这是我的 C4 技能——**challenge-submit-guard（挑战提交自检器）**。
>
> **输入**一个挑战交付文件夹路径，**输出**一份体检报告：缺什么必交物、会不会踩红线
> （无AI日志/一句话提交/缺文件都会封顶扣分）、最可能在哪丢分、按什么顺序补。
>
> 覆盖 C1–C10H 全部 20 个挑战的 rubric 规则，纯 Python 标准库，**不用装任何依赖**。
>
> ```bash
> python challenge_submit_guard.py --self-test      # 3 秒确认能跑（5 个绿勾）
> python challenge_submit_guard.py "你的/交付/文件夹"  # 直接体检
> ```
>
> 我已经拿它跑过我的 C1/C2/C3 三个真实交付包，它在我 C3 包上估 90 分、平台实评 77 ——
> 差的 13 分全是"文件齐但行为没发生"，所以报告里专门有一节"机器查不到必须人工确认的事"。
>
> 欢迎试用和反馈，卡在哪一步直接群里 @ 我，我按反馈出 v5。

## 第二条 · 补充（发布后 30 分钟没人问再发）

> 补充一个最常见的坑：CHALLENGE.md 里写 `.skill` 是 tar.gz，**实测是 ZIP**，
> 用解压软件打开就行。解压后进 `challenge-submit-guard/scripts/` 跑上面的命令。
>
> 另外它判红线很严：AI日志 低于 800 字、或日志里没有"迭代/修改/失败重试"痕迹，
> 都会被判红线（对应评分规则里 -15~20 分的封顶）。交作业前跑一次能省一轮返工。
