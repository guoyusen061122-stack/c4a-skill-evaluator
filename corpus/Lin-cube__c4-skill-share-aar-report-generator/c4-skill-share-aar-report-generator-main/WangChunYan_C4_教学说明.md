# WangChunYan_C4_教学说明.md

> 目标：让一个**从没见过这个技能的人**，5 分钟内装好、跑通、写出第一份复盘报告。

---

## 一、5 分钟上手指南

### 第 1 分钟：拿到技能

技能有「源码目录」和「打包文件」两种形式，任选其一：

- **源码目录**：`aar-report-generator/`（直接可用）
- **打包文件**：`WangChunYan_C4_aar-report-generator.skill`（一个 zip 压缩包）

解压打包文件：

```bash
# Windows：把 .skill 改名为 .zip 后解压，或：
tar -xf WangChunYan_C4_aar-report-generator.skill
```

### 第 2 分钟：确认环境

只需要 Python 3.8+（标准库即可，**无需 pip install 任何东西**）：

```bash
python --version
```

### 第 3 分钟：生成空白模板

```bash
cd aar-report-generator
python scripts/aar_report.py --template -o 我的复盘.json
```

### 第 4 分钟：填模板

打开 `我的复盘.json`，把示例文字换成你的真实经历。**先只填这 6 个最关键的字段**：

| 字段 | 含义 | 提示 |
|------|------|------|
| `title` | 主题 | 一句话 |
| `objective` | 预期目标 | 你本来想达成什么 |
| `what_happened` | 实际过程 | 客观发生了什么 |
| `result` | 结果 | 与预期差在哪 |
| `root_causes` | 根因 | 追问「为什么」 |
| `action_items` | 行动 | 谁、做什么、什么时候 |

### 第 5 分钟：生成报告

```bash
python scripts/aar_report.py 我的复盘.json -o 我的复盘.md
```

打开 `我的复盘.md`，你就有一份完整的复盘报告了。

## 二、不想写代码？两种免代码方式

### 方式 1：纯文本输入

把复盘写成「标签: 值」的 txt 文件（列表用 `-` 开头），一样能生成报告：

```text
标题: 这次小组合作
目标: 三天内完成方案
过程: 分工后各自做，最后一天才合稿
结果: 延期一天，但方案质量高
根因:
- 没有提前定合稿时间
经验教训:
- 先定「合稿日」再分工
行动计划:
- 下次先定合稿时间 | 我 | 下次项目启动时 | 高
```

```bash
python scripts/aar_report.py 复盘.txt -o 复盘.md
```

### 方式 2：把技能装进 Claude，直接对话

安装 `.skill` 后，直接说：

> 「帮我复盘一下这次考试没考好」

技能会用「复盘四问」引导你补全信息，自动生成报告，全程不用碰代码。

## 三、常见坑（都是我实测踩过的）

### 坑 1：Windows 控制台中文乱码

**现象**：`--sample` 输出出现乱码或报错 `gbk codec can't encode`。

**原因**：Windows 控制台默认 GBK 编码。

**解决**：脚本已内置强制 UTF-8 处理，直接跑即可。若仍乱码，是终端显示问题，用 `-o 输出.md` 写文件再看即可。

### 坑 2：JSON 写错了

**现象**：报错 `JSON 解析失败` 或 `不是有效的 JSON`。

**解决**：
- 用 `--template` 生成模板，只改值、不动结构；
- 注意 JSON 里最后一个元素后面**不能有逗号**；
- 不确定就用**纯文本输入**，完全避开 JSON 语法。

### 坑 3：行动项被当成了「经验教训」

**现象**：纯文本里写了「行动计划」，但报告里行动项是空的。

**解决**：行动计划要单独用 `行动计划:` 标签开头，且每条用 `- 行动 | 负责人 | 截止 | 优先级` 的 `|` 分隔格式。

### 坑 4：只填了结果，没填目标

**现象**：深度自检「目标明确」显示 ❌。

**解决**：复盘必须有「预期」才有意义——补上 `objective` 字段，写清你**本来**想达成什么。

## 四、优化技巧（写出高质量复盘）

1. **先量化目标**：把「做好」换成「让 5 个人用起来」，复盘才有判断标准。
2. **根因问 3 层为什么**：别停在「我紧张了」，继续问「为什么紧张」→「因为没排练」→「因为没预留排练时间」。
3. **教训必须能落地**：每条教训配一条行动项，否则就是空话。
4. **诚实归因**：根因指向「自己可改变的」，不要写「运气不好」「队友不给力」。
5. **用深度自检当 checklist**：得分 < 4 说明复盘信息不足，回去补维度。
6. **迭代复盘**：同一件事复盘完执行、执行完再复盘（v1 → v2 → v3），每次补一条新教训。

## 六、常见报错速查

| 报错 | 原因 | 解法 |
|------|------|------|
| `找不到输入文件` | 路径写错了 | 用相对路径或完整路径 |
| `JSON 解析失败` | JSON 语法错误 | 用 `--template` 重写 |
| `gbk codec` | 终端编码 | 用 `-o` 写文件 |
| `not enough values to unpack` | 旧版脚本 bug | 已修复，用最新 `aar_report.py` |
