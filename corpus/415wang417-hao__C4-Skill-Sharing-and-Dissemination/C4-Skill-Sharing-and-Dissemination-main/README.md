## 三、主挑战 C4 要点

**任务**：打造一个可分享、可被他人复用的技能（Skill），并在群内传播、被他人实际使用。

**一个合格技能需同时满足四个条件**：

1. **可复用** —— 换一个人、换一份输入，仍然能跑出结果；
2. **可执行** —— 有明确的操作入口，不只是一段想法；
3. **可验证** —— 能用具体输入产出可检查的输出；
4. **IO 明确** —— 输入是什么、输出是什么，一目了然。

**评审取向（按权重从高到低）**：

1. **被使用次数**（最高权重）—— 技能是否真的被别人拿去用了；
2. 使用效果反馈 —— 使用者是否得到了想要的结果；
3. 复用性 / 易用性 —— 上手成本与迁移成本是否足够低。

**激励**：主挑战评选前 3 名进入 Elite20。

> 结论性提示：权重最高的是「被使用次数」，因此**尽早把技能做出来并推向群内使用**，比反复打磨细节更关键。

### `.skill` 包格式

`.skill` 本质是 **tar.gz** 压缩包，内部布局：

```
技能名/
├─ SKILL.md          # 必需：YAML frontmatter 含 name + description
├─ scripts/          # 可选：可执行脚本
├─ references/       # 可选：参考资料
└─ assets/           # 可选：素材
```

**三层加载机制**：

1. **元数据层** —— frontmatter 的 `name` + `description`，约 100 词，常驻模型上下文，用于判断「什么时候该用这个技能」；
2. **SKILL.md 正文层** —— 理想控制在 500 行以内，讲清操作流程；
3. **附加资源层** —— 按需加载；`scripts/` 下的脚本可直接执行，无需先读入上下文。
