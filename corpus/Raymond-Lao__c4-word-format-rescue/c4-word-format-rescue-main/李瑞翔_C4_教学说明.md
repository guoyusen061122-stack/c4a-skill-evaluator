# 李瑞翔_C4_教学说明.md

## 这个文档教你什么

教你怎么把 word-format-rescue 用起来——包括零基础用法和进阶用法，以及别人踩过的坑。

## 一、30 秒上手（最简单的方式）

1. 把 `SKILL.md` 的内容复制发给任意 AI 助手（Claude / WorkBuddy / ChatGPT 都行）
2. 补一句话："帮我按这个技能的流程，给我的文档排版"，同时上传你的 docx
3. 把老师的格式要求发给它（文字、截图都行）
4. 它会先列方案给你确认 → 确认后执行 → 给你验收对照表
5. 打开排版后的文档，重点看表里标 ⚠️ 的项

**就这样，不需要装任何东西。**

## 二、进阶用法（更快、可机器验收）

如果你电脑有 Python（3.8+）：

```
pip install python-docx
python format_rescue.py 你的文档.docx 格式要求.json
python verify_result.py
```

- 格式要求不会写 JSON？打开 `references/格式要求模板.json`，照着改几个字就行
- 脚本会自动备份原文件（`_bak.docx`），改坏了随时能退回

## 三、常见坑（前人踩过的）

| 坑 | 现象 | 怎么躲 |
|----|------|--------|
| ① 给的是 .doc 老格式 | 脚本报错打不开 | 先用 Word/WPS"另存为 .docx"再排 |
| ② 不给格式要求就说"排个版" | AI 只能瞎猜 | 把老师的要求原文发过去；实在没有就让它按通用学术格式来 |
| ③ 文档里手动敲空格缩进 | 排完格式打架、忽左忽右 | 技能会自动清理，但如果看到奇怪的空段，删掉再排更干净 |
| ④ 封面填空线（姓名：____） | 自动排版对不齐 | 这是正常 ⚠️ 项，需手动微调，技能会告诉你怎么调 |
| ⑤ 图文混排的文档 | 图片位置可能跑 | 技能默认不动浮动图片，看 ⚠️ 提示自己手动拖一下 |
| ⑥ 只改行距却全文重排 | 原本对的地方也被动了 | 明确说"只修被老师点名的项"，技能有局部修复模式 |
| ⑦ 下划线右半截显示不出来 | "姓名：___李瑞翔"线在内容前、后面断掉 | **不是数据错了**，是 Word 默认不画行尾空格的下划线。用 v2 脚本会自动开 ulTrailSpace 开关，且设置随文档保存，别人打开也正常 |
| ⑧ 内容在下划线里偏半格 | 名字不在下划线正中间 | 空格宽度只有 0.5 格粒度，中文姓名场景可精确居中；纯英文/数字极端场景差半格时，把下划线总宽 ±1 调奇偶 |
| ⑨ 保存时提示被占用/失败 | 脚本报 PermissionError | 文档正开着（Word/WPS 锁定文件），关掉再跑；脚本会自动另存"_修复版"保底 |

## 四、怎么判断"排好了"

**别只看肉眼看不出问题就交。** 验收对照表是机器重新打开文档核对真实属性后
生成的，每项都有实际参数（字体名、字号、缩进值……）。表格里全 ✅ 才算排好；
有 ⚠️ 的项目按提示手动检查。

## 五、优化技巧（反馈渠道）

用的时候有任何不顺手（比如你的标题格式是"第1章"而不是"一、"，识别不到），
把情况发给作者，会收录进下一版：
- v2 计划：更多标题编号模式、目录自动生成、页眉设置
- 欢迎提交你的"格式要求原文"，帮你确认能不能识别
