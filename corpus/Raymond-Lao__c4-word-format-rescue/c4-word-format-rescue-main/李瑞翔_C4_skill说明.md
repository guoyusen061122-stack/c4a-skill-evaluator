# 李瑞翔_C4_skill说明.md

## 技能名称

**word-format-rescue（Word 作业排版急救包）**

## 一句话介绍

**输入**一份格式乱的 docx 文档 + 一份格式要求，**输出**排好版的新文档 + 一张"要求 vs 实际"逐项验收对照表。

## 解决什么问题

学生交作业、实验报告、申请书、论文时，老师都会给一堆格式要求（字体、字号、行距、页边距、标题样式、页码……），手动改有三个痛点：

1. **繁琐**：全文几十段，一段段选中改格式
2. **容易漏**：改完发现页码忘了加、某个标题漏改
3. **改错返工**：手动敲空格缩进和段落设置打架，越改越乱

这个技能把排版变成标准化流程：**先核对要求 → 诊断差距 → 列方案确认 → 逐项修改 → 机器验收打勾**。每一项要求都有落点、可追溯，而不是 AI 随口说"排好了"。

## 使用场景

- 实验报告 / 课程论文按老师要求排版
- 申请书、报名表按学校模板调整格式
- 论文格式被打回，只需修复被点名的项目
- 手动敲空格缩进、格式打架的"重灾区"文档抢救

## 输入 / 输出

| | 内容 |
|---|---|
| **输入** | ① 一份 .docx 文档（.doc/.wps 先转格式）② 一份格式要求（文字通知、截图、或模板文档均可） |
| **输出** | ① 排好版的新文档（原文件不动，自动留 `_bak` 备份）② 逐项验收对照表（每项 ✅/⚠️ + 实际参数） |

## 使用步骤

1. 把 SKILL.md 发给 AI（或安装 .skill 包），说"帮我按老师要求排版这份文档"
2. 提供文档 + 格式要求；如果没给要求，AI 会出示【常用格式清单】让你填空，不会瞎猜
3. AI 诊断文档 → 列出"要求 → 操作"方案表给你确认
4. 确认后执行排版（可用配套脚本 `format_rescue.py` 一键完成）
5. 拿到验收对照表，打开文档重点检查标 ⚠️ 的项目

## 真实案例（第一轮测试记录）

用一份故意造乱的《数据结构实验报告》测试（标题不居中、手动敲空格缩进、五号字、无页码），
模拟老师要求：黑体三号标题居中、宋体小四正文、1.5 倍行距、首行缩进 2 字符、
页边距上下 2.5/左右 3.0cm、页码"第 X 页 共 Y 页"底部居中。

机器验收结果（重新打开文档核对真实属性，非口头承诺）：

| 检查项 | 结果 |
|--------|------|
| 正文宋体小四 + 1.5 倍行距 | ✅ eastAsia=宋体, 12pt, 行距=1.5 |
| 五个标题黑体三号居中 | ✅ 命中 5 个标题段全部套用 |
| 首行缩进 2 字符（字符制） | ✅ 8 个正文段全部 firstLineChars=200 |
| 手动空格清理 | ✅ 残留 0 段 |
| 页边距 | ✅ 实测 2.5/2.5/3.0/3.0 cm |
| 页脚页码居中 | ✅ PAGE/NUMPAGES 字段存在且居中 |

## 真实案例 2：公文格式重排（v3）

用户提供《党政机关公文格式》要求的**截图**（标题方正小标宋二号、正文仿宋三号、
黑体/楷体/仿宋四级标题、固定28磅行距、页边距上37下35左28右26毫米），
要求把实验报告重排成正式公文版面。

- 截图解析 → 自动生成 18 项排版方案 → 执行 → 6 项机器验收全部通过
- 细节判断：以句号结尾的"1. xxx。"编号完整句子是正文步骤，不是三级标题，不加粗
- "每页22行×每行28字"由字号+行距+页边距自动保证，无需单独设置

## 边界情况（诚实声明）

以下情况技能会**如实标注 ⚠️ 而不是谎报完成**：封面填空线对齐（需手动微调）、
浮动图片/文本框（AI 改动风险大，默认跳过并提示）、复杂表格斜线表头（只调字体不动结构）、
加密文档（无法处理）。
