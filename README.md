# c4a-evaluator —— C4 技能提交自动评审

**输入**一个文件夹（若干 C4 技能提交），**输出**每位作者的完整性矩阵、
四条件得分、红旗清单与改进建议。纯 Python 标准库、离线、确定性、无需 API key。

> C4A 挑战 · 「技能提交自动评审」 ｜ 提交人：guoyusen

---

## 30 秒看懂

C4 每人交五个文件，一个班几十人。人工核对慢且不一致，所以要有自动评审器。
**但"能自动打分"是不够的 —— 机械检查可以被骗：**

| 骗法 | 朴素评审器 | 本评审器 |
|---|---|---|
| 五个文件名全对，内容全空 | 完整性 5/5 | 空文件不进槽位 → 完整性低 + 红旗封顶 |
| 正文堆满「测试/安装/输入/输出…」 | 满分 | 结构项/信号比值过低 → 封顶 60 |
| 写「本项目**没有**测试」 | 命中「测试」→ 判为**有**测试 | 否定语境闸门 → 该次命中作废 |

**第三条最荒谬：一个什么都没做的提交，能靠"声明自己没做"拿到分。**

这不是设计口号。`tests/` 里有可跑的对照实验：同一批 20 个标注样本上，
朴素的 `NaiveEvaluator` 有 2/18 落到人工标注区间之外，本评审器 **18/18**。

## 跑起来

```bash
# 对自己的提交跑一次（不需要 pip install）
python skill-evaluator/scripts/c4a_evaluator.py <你的文件夹>

# 先看看它长什么样 —— 跑仓库自带的 8 份真实提交
python tools/class_report.py
start reports/评审报告.md
```

四种输出：`评审报告.md` / `评审详表.csv` / `评审仪表板.html` / `评审结果.json`。
退出码：`0` 成功 / `2` 路径错 / `3` 没找到文件（**不假装评了 0 分**）。

## 主要指标（真实跑出来的）

| 指标 | 本评审器 | 朴素对照组 |
|---|---:|---:|
| 综合分落在人工标注区间 | **18/18** | 16/18 |
| 等级一致 | 17/17 | — |
| 红旗 精确率 / 召回 / F1 | **1.00 / 1.00 / 1.00** | — |
| 断言 | **87 通过 / 0 失败** | — |

- **确定性**：同一输入两次运行 JSON 逐字节相同
- **鲁棒性**：整目录改名后分数不变
- **真实语料**：8 份公开 C4 提交、159 个文件、识别出 8 位作者
- **外部校准**：`阮如意` 那份公开 AI 初评 **90/100**，本评审器给 **0.92**

> **这份可靠性的边界（必须说清）**：评测样本是我自己造的，评审器也是我自己写的。
> 自造样本上全对只能证明**实现符合设计**，不能证明**设计是对的**。
> 详见 `guoyusen_C4A_可靠性测试报告.md` 第六节。

## 三条关键设计（都来自实测踩坑）

**① 作者归因：分不清就不归。**
"最近的父目录当作者"会造出 `challenge-preflight`（技能名）、
`c4-skill-sharing-main`（zip 包装目录）三个幽灵作者，班级人数从 1 变 4。
现在改成四条规则：文件名前缀 → 资料目录排除 → 根目录裸文件排除 →
剩下的单候选才归。归不出来的进「未识别」且**不参与排名**。

**② 否定语境闸门。** 命中点前 8 字符内出现否定词时该次命中作废。

**③ 槽位全局最优匹配（穷举）。**
`张三_C4_skill说明.md` 对 `skill_doc` 和 `executable` 都得 8 分；
贪心会让 `executable` 抢走说明文档，真正的代码没人要。
穷举 5 槽位 × 前 8 候选（最多 9⁵）毫秒级跑完且显然正确 ——
**规模允许时，暴力比聪明的近似划算**。

## 不声称的东西

1. **LLM 复核层未运行。** 协议写好了（`references/llm_review_protocol.md`），
   但本环境没有任何模型 API 凭据 —— 仓库里**没有一条真实 LLM 复核意见**。
   `llm_review.py` 无凭据时明确报错退出，不返回伪造的空结果。
2. **规则层不判内容质量。** 套话写得漂亮的提交能拿高分。这是已知边界。
3. **阈值可能过拟合。** 关键词堆砌阈值 0.55 取自当前语料分布
   （真提交最低 0.667 / 堆砌 0.448），换语料需重定。
4. **只有一处外部校准。** 公开带评分的 C4 提交只找到一份。
5. **评估不了"技能是否被传播"。** 使用记录在平台侧，仓库里拿不到 ——
   所以传播维度只报状态、**不折算分数**（没有证据 ≠ 没被用过）。
